  - 诸瑜伽摄一 遇违缘修一

  - 成就三无离 于境修无偏
  - 遍且深修习 于厉境恒修
  - 不依赖他缘 今当修主要
  - 
  - 不颠倒是非 不时停时修
  - 当坚定而修 以二观察解
  - 不好大喜功 不暴躁易怒
  - 不喜怒无常 莫追求声誉
