內容是「科判」這個文體的系統整理：定義、起源流變、組成結構、術語體系、存在形式、思想脈絡、用途、評價標準、錄入與製作流程、以及一份**科判資源清單**。2017 年建立，最後編輯 2017-07。

## 為什麼值得留

這份東西幾乎是照著 `zhu-combined` 科判層的設計問題在寫：

| 文件裡的概念 | 對應到閱讀器 |
|---|---|
| 「詳科／略科」——18 級詳科收起後 12 級、只展前 6 級就是略科 | 目錄浮層的「收起／展開」與層級控制 |
| 「下鑽／上鑽（Zoom in/out）」「同級切換」 | 麵包屑與目錄跳轉的互動模型 |
| 「科·文對照」三種形式：卷首目錄式、文中換行縮進換字體、**冠科**（眉批置書頁上端） | 經文 `kb-mark` 的夾註樣式可以照這三種取捨 |
| 「單獨原文也可以是科判」（分科意識隱沒在行文裡） | 為什麼有些經找不到獨立科文 |
| 基本資訊欄位：原文及作者／科判版本來源、分科者／錄入者／底本／版本狀態・版本號・日期／更新說明 | 建議補進 `window.KEPAN` 的 edition metadata |
| 序號體系六種：天干地支、英文字母、西方編號、語文序號（一、／（一）／1.／（1）／①）、漢語分節（篇章节）、自編符號 | 科判節點若只存 `lab`，要能容納這些寫法 |
| OPML 當交換格式 | 若之後要跟 XMind／幕布／WorkFlowy 互轉，OPML 是共同分母 |

「科判資源」那一段（文件末尾）直接列了**去哪裡找科判文本**：上海佛學書局《佛經科判選編》19 種、CBETA 內科判、kepan.org、強梵暢《法要大藏經》，以及江味農（金剛經）、太虛、圓瑛（楞嚴）、印順、斌宗（心經）、倪維泉（法華）各家科判。金剛經江味農那套已經在 `vcpp` 裡，其餘是可接續的線索。

## 檔案

```text
kepan-refs/
  crawl.mjs          抓取器（Edge headless + CDP）
  docs/科判研究.md    縮排大綱（290 節點，筆記以 > 呈現）
  科判研究.json       純結構樹 {t, note?, k?} + 原始節點數
  README.md
```

## 抓取方式

Dynalist 沒有匿名 HTTP API：`/api/v1/doc/read` 要 token，`/api/file/load`、`/api/bundle_binary` 直接 GET 都回 404（那是頁面內 XHR 才會帶的東西）。但公開文件頁載入時會抓 `/api/bundle_binary`，回應裡就有整份文件的節點樹（`bundle[].path === "/api/doc/load"`）。

所以 `crawl.mjs` 用本機 Edge 開頁面、把那個回應截下來解析。**原始節點清單有 469 筆，但 178 筆是早已刪除、不在樹上的孤兒節點**（Dynalist 只標記、不真正移除）；實際大綱 290 個節點，其中 2 個是空白條目，其餘 288 個有內容、深度 9 級。

```powershell
node kepan-refs/crawl.mjs                                   # 預設那份
node kepan-refs/crawl.mjs https://dynalist.io/d/<id> 檔名    # 別的文件
```

需要 Edge（`EDGE_PATH` 可覆寫）。約 20 秒。

## 限制

- 只抓文字與連結；文中圖片以 Markdown 圖片語法保留（全文只有 1 張，會性法師《天台四教儀》科判手稿）。
- 內容是 2017 年的個人整理，連結多已失效（微信公眾號那幾篇大致還在，百度文庫、365fo 那幾條不保證）。
- 這是**方法論**，不是任何一部經的科判；要科判文本，看 `mubu-kepan/` 或文件末尾那張資源清單。
