## 圖中的例子

- **十一層科文**：《金剛經》第 4 分首句「復次，須菩提！菩薩於法，應無所住，行於布施。」江味農的祖先鏈為
  甲次別解文義 → 乙次正宗分 → 丙次如來讚許 → 丁次許說 → 戊次詳談 → 己初約境明無住 → 庚初的示無住以生信 → 辛初明示 → 壬次明不住於相即是正住 → 癸初正明無住 → 子初標示。
  依《講義》卷二（CBETA B23）科文句逐條核對。
- **消文**：僧肇《金剛般若波羅蜜經注》（卍續藏 X454）開頭五條，依原文次序重排為兩欄。
- **三者合一**：卷二「初證信序」一頁的科句、經文、三段注文。

## 數字

- 經文：江氏自計 5,837 字（不含標點，並魏譯數行計之）。
- 科文：全書二百餘條；層級以天干地支標記，甲至癸十位、子至亥十二位，理論可標二十二層，此書實際用到十八層（未）。
- 昭明三十二分：舊題梁昭明太子，一層。

## 底本

江味農《金剛般若波羅蜜經講義》，CBETA《大藏經補編》No. 23（法鼓文理學院 DILA 數位典藏）。引文一仍底本，標點從原書。
